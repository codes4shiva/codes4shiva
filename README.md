# 🚀 Featured Projects

## 🏘️ ApnaArea — Hyperlocal Social Network

> **Java • Spring Boot • Spring Security • Spring Data JPA • Hibernate • PostgreSQL • React • TypeScript**

- Built a hyperlocal community platform supporting Residents, Sellers and Moderators.
- Developed REST APIs for Follow, Block, Messaging and Community Feed modules.
- Implemented transactional privacy engine with automatic follow removal after blocking.
- Used MapStruct + Lombok for efficient DTO mapping reducing boilerplate.
- Responsive React frontend with optimized client-side rendering.

🔗 **Live:** https://apna-area-hyper-local.vercel.app/

🔗 **GitHub:** https://github.com/codes4shiva/ApnaArea_HyperLocal

- Layered architecture following Controller-Service-Repository pattern.
